Generate, list, get, and revoke Cloudflare API tokens.

### Usage

```bash
goGenerateCFToken token
```

| `--quiet` | `-q` | false | bool | Suppress all output except errors |
| `--verbose` | `-v` | false | bool | Enable verbose output |
